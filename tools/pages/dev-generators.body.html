Dev: Generators

Most of the mod's data and this whole Cobble Valley section are generated, so they stay true to the real pack. The rule: edit the script's tables, never the output. Run every script from its repo's root with python -I.

In the Mod (cobble-valley-ages/tools/)

gen_data.pyIts own tables: AGES, SEEDS, COBBLEMON_RULES, DECOR_BOOK_RULES, DISCIPLINES, MUST_LEARN, CRATES, CRATE_EXTRAS, TUNING, LANGages, seeds, item_rules, tags, disciplines, badge map, tuning, crate and reward loot, bushcraft recipes, item models, en_us.json

Generators delete their old output first (files only, because OneDrive locks folders), so renamed things don't linger. Hand-made quests go in advancement/custom/, hand-made books in books/custom/.

The Dump

gear.json and age_dump.csv must come from a server with the whole pack, because ages depend on every mod's recipes:

python -I tools/test_server.py run <dir>          # runs "cvages age" and "cvages dump"
cp <dir>/config/cvages/age_dump.csv <dir>/config/cvages/gear.json tools/
python -I tools/gen_quests.py
python -I tools/gen_books.py
./gradlew build

Redo this after any change to the pack's mods or to seeds and rules.

The Wiki (modpack/tools/pages/)

FileRole
make.pyRuns everything below in order. Usually all you need.
gen_cobblevalley.pyCopies the mod's data into modpack/data/cvages/ (dump, gear list, ages, disciplines, tuning, books, quests, crate loot, the chest table parsed from LootInjection.java), writes generated/*.html fragments, and writes the "In Cobble Valley" box into every existing page (between <!-- cv-box --> markers). The PAGES table says what each page's box shows.
build.pyTurns <name>.body.html (+ optional <name>.recipes.json) into docs/<name>.html with the site's look. <!-- include: generated/x.html --> pulls in a fragment.
cv-*.body.html, dev-*.body.htmlThe hand-written pages. Edit these.
generated/Output only; regenerated every run.

Pages without a body file (most of the older guide) are edited directly in docs/; only their box is generated. A new page also needs an entry in the GROUPS list in docs/index.html.

Full Regeneration

# in cobble-valley-ages/
python -I tools/gen_data.py
python -I tools/test_server.py run <dir>   # then copy the dump into tools/
python -I tools/gen_quests.py
python -I tools/gen_books.py
python -I tools/gen_adventures.py
python -I tools/gen_trials.py
./gradlew build
# in modpack/
python -I tools/pages/make.py               # reads ../cobble-valley-ages by default
