Dev: Troubleshooting

Problems we've actually hit building this mod, and what fixed them.

Building

SymptomFix
"Unable to delete directory" / file in use during a buildOneDrive locks build output. The build dir is set to ~/.gradle-builds/cvages in build.gradle; keep it there. Generators delete files, not folders, for the same reason.
Gradle says the Java version is unsupportedLoom 1.18 needs JDK 25 to run Gradle: export JAVA_HOME="/c/Users/thoma/.jdks/jdk-25.0.4.1+1". The code still targets Java 21.
A Python one-liner breaks on an apostrophe in Git BashPut the script in a file (heredocs mangle quotes and backslashes here).
PowerShell can't open long Loom cache pathsMAX_PATH; use Git Bash or copies in ~/.gradle/caches/modules-2.

In Game

SymptomCause and fix
An item is in a weird age/cvages why <item>. Usual causes: a recycling recipe, a loop with a cheap way in, a seed missing. Fix with a seed or rule (How-To).
Crafting result flickers or a "ghost" result appearsThe client and server disagree about the result. All three result loads in CraftingMenuMixin must be patched; a mod with its own crafting grid falls to the SlotMixin backstop (free, full-quality crafts only).
Nothing seems to apply when testingYou're in creative or spectator (they bypass everything), or cvagesEnabled is false.
Armor shows no penaltyArmor stats come from item defaults; SkillEffects reads them through forEachModifier. A new armor mod with odd attributes may need a look.
Badges not countingThe leader's advancement id isn't in badge_sources.json (check the RCT jar's data/rctmod/advancement/trainers/). Quick fix: /cvages badges add <leader>.
A furniture item has no bookIt has no recipe (books only cover craftable items), or the dump is older than the mod. Re-dump and rerun gen_books.py.

Data and Loading

SymptomCause and fix
"Found validation problem ... Unknown loot table cvages:prize_crates/extras/..."Normal without Cobblemon (GameTests): the extras tables only load with it. On the real server it must not appear.
Advancement errors about unknown items on the serverA hidden quest names an item from a mod that's gone. Generated auto quests carry fabric:load_conditions; regenerate after removing a mod.
"Mixin apply failed" at startupA Minecraft/mod update moved a method. Check the target and descriptor; the failing mixin is named in the log.
Data changes don't show upBuilt-in JSON is in the jar: rebuild. Datapack overrides need /reload. The age table rebuilds on reload and syncs to players.
Test server won't start: "You need to agree to the EULA"test_server.py setup <dir> --accept-eula.
