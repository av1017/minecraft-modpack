Building

cd minecraftServer/cobble-valley-ages
export JAVA_HOME="/c/Users/thoma/.jdks/jdk-25.0.4.1+1"   # Git Bash
./gradlew build          # compiles, runs all GameTests, writes the jar
./gradlew runGameTest    # just the tests
./gradlew runClient      # a dev client with only this mod
  • The jar is ~/.gradle-builds/cvages/libs/cvages-0.1.0.jar. The version is in gradle.properties.
  • The build folder lives outside OneDrive because OneDrive locks files mid-build.

The Change Loop

  1. Rules, numbers, books, quests: edit the tables in tools/gen_*.py, run the generator, rebuild. How-Tos
  2. Behaviour: edit Java; add or update a GameTest. Testing
  3. ./gradlew build (all tests must pass).
  4. Full-pack check: python -I tools/test_server.py run <dir>, then copy the new dump into tools/ and regenerate quests and books.
  5. Regenerate the wiki: python -I tools/pages/make.py in the modpack folder. Generators
  6. Commit both repos, add a log entry, and release when ready. Releasing
