Join Our Server in 4 Steps

You'll install two free, well-known apps, open one file Avery made, and click Join. No settings to figure out, no typing commands. Take it one step at a time, and if anything looks different from what's written here, stop and text Avery. That's totally fine and expected.

0 / 0 checked

Before you start: text Avery two things

  1. Your Minecraft name (the one you see when you play Java Edition). Avery puts it on the guest list, so the server lets you in and nobody else.
  2. The email address you want to use for Tailscale in step 1. A Google, Microsoft, or Apple email all work. Avery uses it to send you an invite.
  • Texted Avery my Minecraft name and email

1Tailscale: the private link to the server

  1. Go to tailscale.com/download, download it for your computer, and install it.
    Windows: if it asks "Do you want to allow this app to make changes?", click Yes. Mac: if it asks to add a VPN configuration, click Allow.
  2. Open Tailscale and click Log in. Sign in with the same email you texted Avery.
  3. Open the invite link Avery sends you and click Accept.

That's it. Leave Tailscale running. It just needs to be on when you play.

Why this is safe: Tailscale is a free app from its official site, used by millions of people and companies. The invite connects you to Avery's Minecraft server and nothing else. Avery's server can't reach into your computer, and neither of you can see each other's files. Avery can remove the invite any time, and you can uninstall it any time.
  • Tailscale installed, signed in, invite accepted

2The Modrinth App: a launcher for mods

  1. Go to modrinth.com/app, download it, and install it (same "Yes" / "Allow" questions as before).
  2. Open the Modrinth App and click Sign in. A Microsoft window opens: sign in with the account you play Minecraft with.
Why this is safe: Modrinth is the official home of most Minecraft mods, and the app is free from its own site. Your password goes only to Microsoft's sign-in window, never to Avery or to us. It runs Minecraft separately from your normal game, so your regular Minecraft and worlds stay exactly as they are.
  • Modrinth App installed and signed in

3Open Avery's mod pack

  1. Download this file: Cobble-Valley-Cobblemon.mrpack. Don't open or unzip it.
  2. In the Modrinth App, click the + button on the left, then From file, and pick the file you just downloaded. (Or drag the file onto the Modrinth App window.)
  3. Wait while it downloads everything. A new game called Cobble Valley (Cobblemon) appears.
  4. Click it, then the ⚙ Settings gear, then Java and memory. Turn on custom memory and set it to 6144.
    If your computer has less than 16 GB of memory, or you're not sure, just text Avery and we'll pick together.
Why this is safe: the file is tiny and has no programs in it. It's a list telling the Modrinth App which mods to download, straight from each mod's official Modrinth page, plus our key settings. It's the same set Avery, Erin, and Jacob play with.
  • Pack opened and memory set to 6144

4Play!

  1. Make sure Tailscale is on.
  2. In the Modrinth App, click ▶ Play on Cobble Valley (Cobblemon). The first start takes a few minutes. That's normal.
  3. Click Multiplayer. Cobble Valley is already in the list. Click it, then Join Server.

You're in! Avery will show you around. If you're curious, the Pokémon basics page explains catching and battling.

  • Joined the server

Stuck? Text Avery.

Send a photo of your screen and say which step you're on. Common ones, so you know they're not your fault:

  • "Not white-listed": Avery hasn't added your name yet.
  • "Can't connect": check that Tailscale is on, then try Cobble Valley (backup address) in the list.
  • Something about mods not matching: Avery updated the pack. Download the file again and repeat step 3.
  • The game closes while loading: usually the memory setting in step 3.
