Dev: How-Tos

Step-by-step for the changes you'll actually make. Each ends the same way: rebuild, test, regenerate the wiki, commit. Paths are relative to cobble-valley-ages/ unless they say modpack/.

Move an Item to Another Age

  1. Find out why it's where it is: /cvages why mod:item (needs op) or look it up in tools/age_dump.csv.
  2. If a key material is wrong, fix it at the source: add it to SEEDS in tools/gen_data.py (everything made from it follows).
  3. For one item or a mod, add a rule to COBBLEMON_RULES (or a new list written to its own item_rules file): {"match": "mod:item", "age": "iron"}.
  4. python -I tools/gen_data.py, ./gradlew build, then check with /cvages why on the test server.

Make Something Must-Learn, Book-Only or Free

  • Must-learn: add the id to MUST_LEARN (a tag) or a rule with "policy": "must_learn". Give it a visible quest in QUESTS (gen_quests.py) so players can learn it.
  • Book-only: add a match to DECOR_BOOK_RULES, then rerun the dump and gen_books.py so a book teaches it.
  • Free again: a later rule with "policy": "auto" (exceptions go after the rule they except).
  • Never gated at all: "policy": "exempt".

Change a Number

Edit TUNING in gen_data.py, regenerate, rebuild. To try a value on a live server first, put a datapack with data/cvages/cvages/tuning.json in the world's datapacks/ and /reload. Every field is explained on Data Files. For "everyone learns faster/slower" use the gamerule: /gamerule cvagesPracticeRate 150.

Retune an Age

Change badges, group quests or dimensions in AGES (gen_data.py), and the matching text in AGE_TEXT (gen_quests.py). Adding a whole new age means a new row in both, a cvages.age.<id> name (automatic), crate tables (CRATES, CRATE_EXTRAS), and CSS for its chip in modpack/tools/pages/build.py.

Add a Visible Quest

  1. Add a row to QUESTS in tools/gen_quests.py: (age, item_key, icon_or_None, title, {ingredient: count}, previous_tier_or_None). Ingredients can be #tags or a|b|c alternatives.
  2. python -I tools/gen_quests.py. It writes the advancement, the reward function and the crate reward.
  3. Hand-made advancements (any shape) go in data/cvages/advancement/custom/; the generator never touches them.

Add a Discipline

  1. Add it to DISCIPLINES in gen_data.py: name, age, proxy items, gated blocks.
  2. To gate recipes too, add rules with "discipline": "<id>".
  3. Add its quest to QUESTS with the key cvages:discipline/<id>.
  4. Regenerate both, rebuild. The wiki's discipline table updates itself.

Change Books

Books are generated: change MAX_FAMILIES, MAX_ITEMS, the variant words or MOD_NAMES in tools/gen_books.py and rerun it. To hand-make a book, put a JSON in data/cvages/cvages/books/custom/ and remove those items from the generated ones (or they'll be in two books, which is harmless).

Change Crate Loot or Odds

  • Contents: CRATES and CRATE_EXTRAS in gen_data.py (books rolled, supplies, Pokémon extras).
  • Hidden-quest chance: HIDDEN_QUEST_CRATE_CHANCE.
  • Structure and trainer odds: the table at the top of content/LootInjection.java (rebuild needed).

Add a Mod to the Pack

  1. In modpack/: tools/add-mod.ps1 -Pack cobblemon -Slug <slug>. Check its keys (modpack CLAUDE.md).
  2. python -I tools/test_server.py setup <dir> picks it up; run <dir> dumps the new table.
  3. Copy <dir>/config/cvages/age_dump.csv and gear.json into tools/.
  4. Read the new mod's rows: anything in the wrong age gets a seed or rule; decor gets a BOOK rule; then gen_data.py, gen_quests.py (hidden gear quests), gen_books.py.
  5. Rebuild, rerun the test server (zero errors), then python -I tools/pages/make.py in modpack/ and add the mod to the right "In Cobble Valley" box in gen_cobblevalley.py if it has a page.
