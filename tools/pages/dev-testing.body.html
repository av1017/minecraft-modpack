GameTests

./gradlew build runs them; ./gradlew runGameTest runs only them. Source: src/gametest/java/.../CvAgesGameTests.java. A tiny test datapack (src/gametest/resources/data/cvagestest/) adds test books and makes the flower pot, item frame, painting and lantern book-only.

Writing one: use the survivor(h) helper (the vanilla mock player is always creative, which bypasses the mod), set ages with ages(s, ...), do the work in the first tick, and remove(p) your players before checking. Tests share one server, so never rely on state another test left.

Full-Pack Server

python -I tools/test_server.py setup C:\cvtest --accept-eula   # once; again after pack changes
set JAVA21=C:\Users\thoma\.jdks\jdk-21.0.12.1+1\bin\java.exe
python -I tools/test_server.py run C:\cvtest "cvages age" "cvages dump" "cvages why minecraft:torch"
  • It copies the freshly built jar in each run, waits for "Done", runs your commands, stops, and prints the lines that matter. The full log is cvrun.log.
  • Must be clean: no "validation problem", "Couldn't parse", or advancement errors. ("No data fixer registered" lines are normal for modded entities.)
  • Handy checks: loot spawn 0 100 0 loot cvages:prize_crates/iron, loot spawn 0 100 0 loot rctmod:trainers/groups/leader (should drop a crate).

Playtest Checklist

In a laptop survival test world with the full pack. Your checkmarks save in this browser.

  • First join: a Wood Age Prize Crate arrives; opening it gives a book and supplies.
  • Leaves drop by hand sometimes; craft a leaf bed from sticks; sleep in it; set spawn.
  • Leaf torches and a coal-free campfire craft.
  • Holding planks + sticks masters the wooden pickaxe; crafting table + pickaxe completes First Steps (Stone Age title).
  • A furniture recipe is refused until you read its book; then it crafts normally.
  • Farmer's Delight cooking pot won't open until Cooking is learned (quest).
  • Skill rises with use; tooltip numbers move; a Crude craft at low skill.
  • A lesson with a second account (crouch + right-click), and its cancel rules.
  • An iron ingot is a Strange Object in the Stone Age; carrying it reveals it.
  • Beat a gym leader: badge counts, Iron Age unlocks, leader drops a crate.
  • The Nether portal refuses before the Nether Age.
  • Skim tools/age_dump.csv (or Item Lookup) for items in a surprising age, and the BOOK list.
