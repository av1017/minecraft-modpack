Dev: Releasing

Same path as Twin Portals: a GitHub release on the modpack repo, a pinned entry in the cobblemon mods.json, then the server and the friends' pack. Order matters: never push the manifest before the release asset exists, or everyone's sync fails to download it.

Release Steps Updating the Server The First Launch Versions

Release Steps

  1. Bump version in gradle.properties; ./gradlew build (all tests pass); full-pack server run is clean.
  2. Commit and tag the mod repo: git tag cvages-vX.Y.Z.
  3. Upload the jar as a release on av1017/minecraft-modpack: gh release create cvages-vX.Y.Z ~/.gradle-builds/cvages/libs/cvages-X.Y.Z.jar --title "Cobble Valley Ages X.Y.Z" --notes "..."
  4. Edit the pack's entry by hand (it's pinned, so add-mod.ps1 leaves it alone): filename, url (the release download link), version, version_id, and sha1 (sha1sum of the jar). project_id: "cvages-local", side: "both".
  5. Regenerate the wiki (python -I tools/pages/make.py), commit and push the modpack repo.
  6. Update the server (below), then rebuild the friends' pack: python -I tools/build-friends-pack.py --upload.
  7. Add a log entry.

Updating the Server

  1. Tell people first if anyone may be playing.
  2. Over 3 minutes of downtime? sudo touch /var/lib/homeserver/watchdog/maintenance so the watchdog doesn't page you.
  3. ssh homeserver-lan (Proton VPN blocks the Tailscale route), then run update-mods.py in /srv/homeserver/services/minecraft: it syncs the side:both mods from the manifest and restarts the container.
  4. Check the log for a clean start and "Cobble Valley Ages data: ..." with the expected counts.
  5. Remove the maintenance flag; commit any server config change and add a server log entry.

The First Launch (Cobble Valley world)

  • Avery's playtest done (checklist); age table and BOOK list reviewed.
  • Release cvages-v0.1.0; add its pinned manifest entry.
  • Release twinportals-v0.5.0 (portal-proof panels) and update its pinned manifest entry. Without it the Trials' dark panels take portals.
  • Merge the modpack cobble-valley branch (Leaf Beds) into main with the cvages entry; push.
  • Server: maintenance flag, back up the sandbox world, update-mods.py.
  • Server env: LEVEL: Cobble Valley, DIFFICULTY: easy, a new seed; commit the compose change.
  • First start: check the log, /ages age shows Wood Age, a test login gets the Wood crate.
  • Place a Puzzle Temple near spawn: stand there as an op and run /place structure cvages:puzzle_temple.
  • Rebuild the friends' pack; update Erin's and Jacob's setup notes; tell everyone to read Start Here.

Versions

  • Patch (0.1.1): fixes, numbers, data. Safe mid-world.
  • Minor (0.2.0): new features (notes, real sleeping enchantments). Safe mid-world; announce changes.
  • Save data uses string keys, so removing or renaming items never corrupts it. Changing an item's age mid-world just changes what's recognized.
  • Clients and the server must run the same version (payloads change between versions).
