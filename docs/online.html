Playing From Anywhere

Friends who don't live with us can join the Cobblemon world over the internet. The host opens the world to LAN like normal, and the e4mc mod gives it a public address to share. No router settings, no server. The world stays on the host's PC, so it's only open while the host is playing.

Hosting (Avery)

  1. Open Reajustiene in the Cobblemon 1.21.1 profile.
  2. Press Esc → Open to LAN → Start LAN World.
  3. A chat line appears: "Local game hosted on domain […]". Click the address to copy it.
  4. Send the address to your friend privately (a text or DM). Erin can still join from the LAN list at home as usual.
  5. When you're done, click "(Click here to stop)" in that chat line, or just quit the world.
  • Open to LAN and copy the e4mc address

Friend's First-Time Setup (Windows)

Once per PC. Our mods have to match exactly, and the sync script installs them for you.

  1. Install Minecraft: Java Edition, sign in, and play vanilla once so the launcher sets itself up. Then close the game and the launcher.
  2. Install Git (in a terminal: winget install --id Git.Git -e).
  3. Get our modpack: git clone https://github.com/av1017/minecraft-modpack.git
  4. In that folder, double-click Sync Cobblemon.bat. It downloads every mod from Modrinth, checks each one, and creates a launcher profile called Cobblemon 1.21.1. It won't run while Minecraft or the launcher is open.
  5. Start the Cobblemon 1.21.1 profile once, wait for the main menu (the first start is slow), and close it.
  6. Run Sync Cobblemon.bat again. A few fixes (key settings and a lighter far-view setting) can only be applied after the first launch.
Only the Cobblemon pack is needed. Don't add or remove mods yourself: joining only works when everyone has exactly the same list.
  • Friend: sync, launch once, sync again

Joining

  1. Start the Cobblemon 1.21.1 profile.
  2. Multiplayer → Direct Connection.
  3. Paste the address the host sent and click Join Server.

The address only works while the host has the world open to LAN. You can save it with Add Server, but the address may change between sessions, so use the newest one the host sends.

  • Friend: join Reajustiene for the first time

Staying Up to Date

When we change the mods, everyone needs the new list before joining.

  1. Close Minecraft and the launcher.
  2. In the modpack folder, run git pull.
  3. Double-click Sync Cobblemon.bat.

If joining fails with a "mismatched mods" or "missing mods" message, someone is behind. Everyone pull and sync.
