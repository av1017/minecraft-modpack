Playing From Anywhere

Our Cobblemon world runs on a home server that stays on all the time, so you can play whenever you like, even when Avery isn't online. Friends connect through Tailscale, a free app that links your computer privately to the server. The whole modpack is one file that you open in the free Modrinth App. It works on Windows and Mac, with no router settings and no command lines.

What You Need

  • Minecraft: Java Edition on a Microsoft account. The version on Xbox, Switch, PlayStation, and phones (Bedrock) can't join. PC Game Pass includes Java Edition.
  • A Windows 10/11 PC or a Mac. 16 GB of RAM is recommended; this is a big modpack.
  • About 2 GB of free disk space.

Send Avery two things before your first visit:

  1. Your Minecraft username, spelled exactly. It goes on the server's guest list (the whitelist). Nobody else can get in.
  2. The email you'll use for Tailscale (step 1 below), so Avery can invite you.
  • Sent Avery my Minecraft username and Tailscale email

1. Tailscale (once)

Tailscale makes the server reachable from your computer, and only from the computers of people Avery invites. The invite lets you reach the Minecraft server and nothing else on Avery's network.

  1. Install Tailscale from tailscale.com/download. On a Mac, the Mac App Store version is fine. When your computer asks to allow a VPN configuration, click Allow.
  2. Sign in with a Google, Microsoft, Apple, or GitHub account. That creates your free Tailscale account. Use the email you sent Avery.
  3. Open the invite link Avery sends you and click Accept.
  4. Check it worked: in the Tailscale menu (system tray on Windows, menu bar on a Mac), a machine called homeserver appears.
Tailscale has to be connected whenever you play. If you switch it off, the server disappears.
  • Tailscale installed, signed in, invite accepted
  • I can see "homeserver" in Tailscale

2. The Modpack (once)

Everyone needs exactly the same mods to join. The pack file installs all of them (84 mods, plus our texture packs and key settings) straight from the mod authors' official downloads.

  1. Install the Modrinth App from modrinth.com/app (free, Windows and Mac). It's a Minecraft launcher made for mods.
  2. Sign in in the Modrinth App with the Microsoft account that owns Minecraft.
  3. Download our pack: Reajustiene-Cobblemon.mrpack. Don't unzip it.
  4. In the Modrinth App, click + (Create an instance) on the left, pick From file, and choose the file you downloaded. Dragging the file onto the app window works too.
  5. Wait while it downloads everything. A new instance called Reajustiene (Cobblemon) appears.
  6. Give it more memory: open the instance, click Settings (the gear), then Java and memory. Turn on custom memory and set it to 6144 MB (8192 MB if your computer has 32 GB of RAM). The default 2 GB is far too little for this pack and it will crash. With only 8–12 GB of RAM, use 4096 MB and turn off Faithful 32x in Options → Resource Packs; it will still be tight.
  7. Click Play. The first start takes a few minutes. Wait for the main menu.
Don't add, remove, or update mods in the instance. Joining only works when your mods match the server's exactly. To update, use the steps under Updates.
  • Pack imported into the Modrinth App
  • Memory set to 6144 MB or more
  • The game reached the main menu

3. Joining

  1. Make sure Tailscale is connected.
  2. Start Reajustiene (Cobblemon) in the Modrinth App.
  3. Click Multiplayer. Reajustiene is already in the list. Pick it and click Join Server.

If Reajustiene shows "Can't connect", try Reajustiene (backup address) just below it. It's the same server, reached by number instead of name. If you ever need to type it: homeserver.tail5e6af0.ts.net or 100.66.188.58.

New here? Start with Pokémon Trail (starters, catching, healing) and Every Key. The keys in this pack differ from plain Minecraft in a few places: C and X work anything you ride, and zoom is `. On a Mac, the guide's Alt is your Option key.

  • Joined the server for the first time

Updates

When we change the mods, Avery will tell you. If you try to join with the old pack, the server turns you away with a message about mismatched or missing mods.

  1. Download the pack again from the same link. It always has the newest version.
  2. In the Modrinth App, create a new instance From file with it, just like the first time, and set the memory again.
  3. Play the new instance. Once it works, you can delete the old one: your character, items, and Pokémon are saved on the server, not on your computer.

Keep your map (optional): before deleting the old instance, open its folder (instance menu → Open folder) and copy the xaero folder into the new instance's folder. Otherwise the minimap starts blank again.

If Something's Wrong

You seeWhat to do
"You are not white-listed on this server"Avery hasn't added you yet, or the name doesn't match. Send Avery your exact Minecraft username.
"Can't connect to server", "Connection timed out", or "Unknown host"Check that Tailscale is connected and shows homeserver. Try the backup address. If both fail, the server may be down for maintenance: ask Avery.
Mismatched, missing, or rejected modsYour pack is out of date (or a mod was added or removed by hand). Do the update steps.
The game crashes while loading, or freezes and closesUsually not enough memory. Set it to 6144 MB or more (step 2.6), or 4096 MB without Faithful 32x on a computer with 8–12 GB of RAM. Close Chrome and other big programs.
Low frame rateShaders are off by default; leave them off. In Options → Video Settings, lower Render Distance to 8. The far-away landscape (Distant Horizons) is already on a light setting.
A key does nothing or the wrong thingCheck Every Key. If you changed a key yourself, Options → Controls → Key Binds has a reset button.

Laptop Hosting (until the real world moves)

Until the server takes over, the real world opens only while Avery is playing it. The e4mc mod gives it a public address for the session.

  1. Avery: open Reajustiene, press Esc → Open to LAN → Start LAN World. Click the address in the chat line "Local game hosted on domain […]" to copy it, and send it to your friend privately.
  2. Friend: start the pack, then go to Multiplayer → Direct Connection, paste the address, and click Join Server. Tailscale isn't needed for this.
  3. Avery: when you're done, click "(Click here to stop)" in that chat line, or quit the world.

Anyone with the address can join while it's open. Treat it like a password, and stop hosting when you're done. The address can change between sessions.
